# What information Site Mapper keeps

Site Mapper shows different types of information that work together.

![Location, connections and readings](/help/diagrams/en/overview.svg)

## Location

Shows **where equipment is located**: site, building, floor, room and rack.

## Equipment and components

Shows **what is inside each rack** and how its parts fit together. A Panel, for example, can contain several breakers.

## Connections

Shows **which terminal on one unit is connected to another**. This is the connection recorded in the system.

## Readings

When a unit sends data, you can view recent values and, when available, their history.

## Why are these separate?

They answer different questions:

| Question                 | Where to look                       |
| ------------------------ | ----------------------------------- |
| Where is it?             | EXPLORE / Blueprint                 |
| What parts does it have? | Rack / Device / Equipment           |
| What is it connected to? | PHYSICAL TERMINALS / VIEW POWERPATH |
| What is it measuring?    | LIVE TELEMETRY / Charts             |

**You're done when:** you know which screen to open to find the information you need.
