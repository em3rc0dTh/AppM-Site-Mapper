# Use equipment from Warehouse

**Warehouse** contains reusable equipment models you can choose when setting up a rack or adding components. A template is a model; the equipment installed from it is a separate unit.

## Find a template

1. Open **WAREHOUSE** in the navigation.
2. Browse the catalog and find the model you need.
3. Check its type and the components it can contain.
4. Open the rack or equipment where you want to use it.

## Install equipment from Warehouse

1. In the Rack or **PHYSICAL COMPOSITION**, open the action to add equipment.
2. Choose **FROM WAREHOUSE**.
3. Select a compatible template.
4. Enter the name and details required for this new unit.
5. Select **Install Equipment**.
6. Reopen its location to confirm the new item appears.

## If there is no suitable template

The Equipment composition screen may offer **ONE-OFF** so you can create an individual component. Enter its name, type and positions if needed.

## Create a template (if your account allows it)

WAREHOUSE lets authorized users create a template using a form or import a prepared JSON file. This is for people responsible for equipment models.

## If installation is blocked

Check that you're adding the unit to the correct parent. Not every template can be placed inside every rack or component.

**You're done when:** you can find a model, install a unit and locate it correctly.
