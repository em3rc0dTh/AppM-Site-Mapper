# Your first Site Mapper walkthrough

You can complete this short tour **without changing any data**. Use it to get familiar with the main screens.

![Your first Site Mapper visit](/help/diagrams/en/overview.svg)

## First stop: find a room

1. Sign in.
2. Select **EXPLORE**.
3. Open a **Network**, then a **Site** and **Structure**.
4. Choose a **Level**, then a **Room**.

**Success:** you can name the room you have opened.

## Second stop: find a rack

1. In the Room, open **Blueprint** if available.
2. Find a rack on the plan.
3. Select it to open its details.

**Success:** you can name the room containing the rack.

## Third stop: find equipment

1. Open a **Device** in the rack.
2. Find its components.
3. Choose a **Panel** and identify free and occupied positions.

**Success:** you can name a unit and one of its components.

## Fourth stop: view a connection or reading

1. Find **PHYSICAL TERMINALS** and open an existing connection if there is one.
2. If **LIVE TELEMETRY** is available, read a value and its timestamp.
3. If no reading is shown, note the message displayed.

You don't need to create equipment or connections to complete this tour.

**You're done!** You can now find a room, rack, equipment and related information.
