# Add terminals and power inputs

**Terminals** represent the points where equipment receives or delivers power. To identify them correctly, you need to know what each one is connected to.

![Source and destination of a power connection](/help/diagrams/en/power.svg)

## View existing terminals

1. Open the Equipment you want to inspect.
2. Find **PHYSICAL TERMINALS** or **ACCESS PORTS**.
3. Select a terminal to see its name, type and status.
4. Check whether it is **INPUT**, **OUTPUT** or **BIDIRECTIONAL**.

## Add a terminal (if authorized)

1. Open the terminal editor from the Equipment page.
2. Enter a clear name.
3. Choose **POWER** for a power connection.
4. Set its direction to **INPUT** or **OUTPUT** as appropriate.
5. Review the other requested details and save.
6. Confirm it appears on the intended Equipment.

## Main power inputs on a BDFB

When setting up an external DC input, the form may ask for **Feed A or B**, connected Panels and input/shunt ratings. Use details from the actual installation.

Only mark a physical input as **verified** after its wiring has been checked.

## If the terminal says CONNECTED

Site Mapper already holds a recorded connection for it. Use **VIEW POWERPATH** to see the linked equipment.

**You're done when:** you can identify each terminal and decide whether to add one or inspect an existing connection.
