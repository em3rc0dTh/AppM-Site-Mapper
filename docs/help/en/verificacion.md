# When equipment readings are missing

Sometimes a unit appears in the inventory but has no recent readings. These checks help you understand what you're seeing.

## Check these first

1. Make sure you've opened the **right equipment**.
2. Check its name and the time of its latest reading.
3. Open history to see if earlier readings exist.
4. If nothing appears, check the status message.

## What do the messages mean?

| Status        | Meaning                                           |
| ------------- | ------------------------------------------------- |
| **LIVE**      | A recent reading is available                     |
| **STALE**     | The latest reading is old                         |
| **NO DATA**   | No value is available to show                     |
| **UNMAPPED**  | A signal has not yet been linked to the equipment |
| **AVAILABLE** | A position is free                                |
| **OCCUPIED**  | A position is in use                              |
| **CONNECTED** | A connection has been recorded                    |

## What should I do?

If a reading is old or unavailable, note the **equipment name**, **time** and **message** on screen. Share that with the person responsible for the system.

## Important

**NO DATA** does not prove the equipment is off. It simply means Site Mapper has no reading available at that moment.

**You're done when:** you understand the displayed status and can describe the issue clearly.
