# Entiende cómo se organiza la infraestructura

Imagina que buscas un equipo en un edificio. Primero eliges el lugar, después la sala, luego el rack y finalmente el equipo.

![Cómo encontrar un equipo dentro de una sala](/help/diagrams/es/places.svg)

## Las partes más importantes

| Nombre en pantalla | Qué significa                               |
| ------------------ | ------------------------------------------- |
| **Network**        | Un grupo de instalaciones                   |
| **Site**           | Una instalación o sede                      |
| **Structure**      | Un edificio o estructura                    |
| **Level**          | Un piso o nivel                             |
| **Room**           | Una sala                                    |
| **Bay / Position** | Un área y una ubicación dentro de la sala   |
| **Rack**           | El gabinete donde se ubican los equipos     |
| **Device**         | Un equipo principal del rack                |
| **Equipment**      | Una pieza o componente dentro de ese equipo |

## Un ejemplo sencillo

Supongamos que necesitas revisar el interruptor de un panel. Puedes seguir este recorrido:

1. Abre la **Network** correspondiente.
2. Entra al **Site** y selecciona el edificio.
3. Busca el **Level** y después la **Room**.
4. Abre el **Rack** donde se encuentra el equipo.
5. Entra al **Device**, busca el **Panel** y selecciona el interruptor.

No necesitas conocer todos los nombres de memoria: el árbol de navegación te ayuda a avanzar.

## ¿Qué diferencia hay entre un rack y un panel?

Un **rack** contiene equipos. Un **panel** es parte de uno de esos equipos y puede tener varias posiciones para interruptores.

**Al terminar:** podrás explicar dónde está ubicado un equipo y cómo llegar a él desde el menú EXPLORE.
