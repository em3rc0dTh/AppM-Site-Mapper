# Crear un sitio, edificio o sala

Cuando necesitas agregar un espacio, debes comenzar desde el lugar donde estará ubicado.

## Antes de empezar

Abre **EXPLORE** y comprueba que estás en la instalación correcta. Si no aparecen los botones para crear espacios, puede que tu cuenta solo permita consultar información.

## Crear un sitio

1. Entra a la **Network** correspondiente.
2. Selecciona **+ CREATE SITE**.
3. Escribe el nombre del sitio.
4. Selecciona **Define boundary** para dibujar sus límites.
5. Revisa el dibujo y guarda usando **Save Site**.
6. Comprueba que el sitio aparece dentro de la Network correcta.

## Agregar un edificio, nivel y sala

1. Abre el sitio y selecciona **+ CREATE STRUCTURE**.
2. Escribe el nombre del edificio, define sus límites y guarda.
3. Entra al edificio y selecciona **+ CREATE LEVEL**.
4. En ese nivel selecciona **+ CREATE ROOM**.
5. Escribe el nombre de la sala, dibuja sus límites y guarda con **Save Room**.

![Cómo se organiza una instalación](/help/diagrams/es/places.svg)

## ¿Cómo sé que se guardó?

Vuelve al árbol de navegación. Deberías poder abrir el sitio, edificio, nivel o sala que acabas de crear.

## Si no puedes guardar

Comprueba que dibujaste un área válida y que la sala está dentro del edificio. Si el botón no aparece, revisa la ubicación que tienes abierta o consulta con tu administrador.

**Al terminar:** la nueva sala aparecerá en el lugar correcto y estará lista para organizar su contenido.
