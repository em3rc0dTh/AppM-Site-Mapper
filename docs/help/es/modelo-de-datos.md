# Qué información guarda Site Mapper

Site Mapper muestra varios tipos de información que se complementan entre sí.

![Ubicación, conexiones y lecturas](/help/diagrams/es/overview.svg)

## Ubicación

Indica **dónde está un equipo**: sede, edificio, piso, sala y rack.

## Equipos y componentes

Muestra **qué hay dentro de cada rack** y cómo se organizan sus piezas. Por ejemplo, un panel puede contener varios interruptores.

## Conexiones

Permite consultar **qué terminal de un equipo está conectado a otro**. Esto representa la conexión registrada en el sistema.

## Lecturas

Cuando un equipo envía información, puedes ver sus valores recientes y, cuando exista, su historial.

## ¿Por qué estas cosas aparecen por separado?

Porque responden a preguntas diferentes:

| Pregunta | Dónde buscar |
| --- | --- |
| ¿Dónde está? | EXPLORE / Blueprint |
| ¿Qué piezas tiene? | Rack / Device / Equipment |
| ¿A qué está conectado? | PHYSICAL TERMINALS / VIEW POWERPATH |
| ¿Qué está midiendo? | LIVE TELEMETRY / Charts |

**Al terminar:** sabrás qué sección abrir para encontrar la información que necesitas.
