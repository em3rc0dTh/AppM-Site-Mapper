# Tu primer recorrido por Site Mapper

Puedes completar este recorrido sin modificar ningún dato. El objetivo es familiarizarte con las principales pantallas.

![Tu primera visita a Site Mapper](/help/diagrams/es/overview.svg)

## Primera parada: encuentra una sala

1. Inicia sesión.
2. Selecciona **EXPLORE**.
3. Abre una **Network**, luego un **Site** y una **Structure**.
4. Elige un **Level** y finalmente una **Room**.

**Lo lograste cuando:** puedes indicar el nombre de la sala que tienes abierta.

## Segunda parada: encuentra un rack

1. En la sala, abre **Blueprint** si está disponible.
2. Localiza un rack en el plano.
3. Selecciónalo para abrir sus detalles.

**Lo lograste cuando:** puedes decir en qué sala se encuentra el rack.

## Tercera parada: conoce sus equipos

1. Abre un **Device** del rack.
2. Busca sus componentes.
3. Selecciona un **Panel** y revisa qué posiciones están libres y ocupadas.

**Lo lograste cuando:** identificas un equipo y una de sus piezas.

## Cuarta parada: observa una conexión o una lectura

1. Busca **PHYSICAL TERMINALS** y abre una conexión existente si la hay.
2. Si el equipo muestra **LIVE TELEMETRY**, consulta el valor y la hora.
3. Si no aparece información, revisa qué mensaje se muestra.

No necesitas crear equipos ni conexiones para completar esta práctica.

**¡Listo!** Ya sabes encontrar una sala, un rack, un equipo y la información que ofrece Site Mapper.
