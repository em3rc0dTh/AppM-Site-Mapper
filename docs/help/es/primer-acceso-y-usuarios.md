# Entrar al sistema y usar tu cuenta

Aquí aprenderás a iniciar sesión y reconocer las opciones de tu cuenta.

## Iniciar sesión

1. Abre la dirección de Site Mapper que te proporcionaron.
2. Escribe tu **correo** y **contraseña**.
3. Selecciona **SIGN IN**.
4. Al entrar verás tu espacio de trabajo (**Workspace**).

Si es la primera vez que ingresas y te piden cambiar tu contraseña, escribe la contraseña actual y después una nueva. Al terminar, vuelve a iniciar sesión con la nueva contraseña.

## ¿Qué pasa si no puedo entrar?

Revisa que hayas escrito el correo y la contraseña correctamente. Si el mensaje continúa, pide ayuda a la persona que administra las cuentas de tu organización. No compartas tu contraseña por mensajes ni capturas.

## ¿Por qué algunas opciones no aparecen?

Site Mapper muestra las funciones de acuerdo con tu tipo de cuenta:

| Tipo de cuenta | Qué puedes hacer                                        |
| -------------- | ------------------------------------------------------- |
| **Standard**   | Consultar espacios, equipos, conexiones y lecturas      |
| **Admin**      | Además, organizar espacios y equipos cuando corresponda |
| **Superadmin** | Además, administrar las cuentas de usuario              |

## Agregar un usuario (solo Superadmin)

1. Abre **ADMIN → Settings → Users**.
2. Selecciona **+ ADD USER**.
3. Completa el **nombre**, **correo** y **tipo de cuenta**.
4. Asigna una contraseña temporal y selecciona **Create user**.
5. Comprueba que la nueva cuenta aparece en la lista.

Comparte los datos de acceso por un canal seguro. La persona deberá cambiar su contraseña al ingresar por primera vez.

**Al terminar:** podrás entrar a tu espacio de trabajo y reconocer qué funciones están disponibles en tu cuenta.
