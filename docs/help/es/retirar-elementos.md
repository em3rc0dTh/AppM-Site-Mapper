# Retirar o archivar un elemento

En Site Mapper, **retirar del plano** y **archivar un equipo** son acciones distintas. Ambas necesitan precaución para conservar la información relacionada.

## 1. Quitar algo del plano de una sala

![EDIT ROOM muestra Remove selected dentro de un borrador no guardado](/help/screenshots/edit-room.png)

1. Abre la **Room** y entra a **Blueprint**.
2. Selecciona **EDIT ROOM**.
3. Selecciona la posición, zona o rack que quieres retirar.
4. Usa **Remove selected** cuando esté disponible.
5. Revisa el plano antes de presionar **SAVE LAYOUT**.

**Si no te deja quitarlo:** una zona puede tener posiciones, una posición puede contener un rack y un rack puede tener equipos o espacios ocupados. Revisa primero qué contiene. No retires otros elementos solo para conseguir que el botón funcione.

**Recuerda:** hasta guardar el layout, el cambio puede seguir siendo un borrador.

![EDIT CAS muestra reservas y asignaciones que pueden impedir retirar un rack](/help/screenshots/rack-cas.png)

## 2. Archivar un Equipment

Si tienes acceso de edición, algunas fichas de **Equipment** muestran el botón **Archive**.

1. Abre la ficha de la pieza correcta.
2. Revisa si contiene otras piezas o si tiene una ubicación asignada.
3. Si **Archive** está habilitado, confirma que deseas retirar ese elemento.
4. Comprueba el estado mostrado por la ficha.

Cuando existan hijos, montaje o relaciones que impidan el retiro, el botón puede aparecer deshabilitado.

## 3. ¿Y eliminar un Site completo?

**La eliminación definitiva de un Site no está disponible como acción habitual.** El sistema dispone de reglas de archivado, pero todavía no ofrece un recorrido general de retiro y restauración desde la ficha de todos los espacios. No busques un botón Delete Site ni intentes quitar una instalación que contiene edificios, salas o equipos.

## ¿Qué pasa con las conexiones y mediciones?

Antes de retirar un equipo con terminales, conexiones o señales asociadas, consulta con quien administra la instalación. Retirar un elemento no debe confundirse con borrar sus registros históricos.

**Resultado:** sabes qué acciones de retiro están disponibles en cada pantalla y cuándo detenerte.
