# Consultar datos en tiempo real

Algunos equipos envían lecturas que puedes consultar directamente en Site Mapper. Así podrás ver si hay información reciente o revisar lecturas anteriores.

![Cómo llegan las lecturas a la pantalla](/help/diagrams/es/readings.svg)

## Ver las lecturas de un equipo

1. Abre la sala y el rack donde está el equipo.
2. Selecciona el equipo o el interruptor que quieres consultar.
3. Busca **LIVE TELEMETRY**.
4. Revisa los valores disponibles y la hora de la última lectura.

## ¿Qué significa cada valor?

| Dato | Qué muestra |
| --- | --- |
| **V / Voltage** | Voltaje |
| **A / Current** | Corriente |
| **W / Power** | Potencia |
| **kWh / Energy** | Energía acumulada |

No todos los equipos muestran siempre las cuatro lecturas: depende de cómo esté configurada su información.

## Ver lecturas anteriores

En la sección de historial, selecciona **24H** para ver el último día o **7D** para revisar la última semana, cuando esos datos estén disponibles.

## Si aparece STALE o NO DATA

La pantalla no tiene una lectura reciente para mostrar. Eso no significa necesariamente que el equipo esté apagado. Consulta la guía [Si un equipo no muestra datos](verificacion.md).

**Al terminar:** podrás revisar un valor, su unidad, cuándo fue recibido y cómo consultar el historial.
