# Si un equipo no muestra datos

A veces un equipo aparece en el inventario, pero no muestra lecturas recientes. Esta guía te ayudará a entender qué ocurre.

## Comprueba primero

1. Asegúrate de que abriste el **equipo correcto**.
2. Revisa el nombre y la hora de su última lectura.
3. Abre el historial para comprobar si tuvo datos anteriormente.
4. Si sigue sin mostrar información, consulta el mensaje de estado.

## ¿Qué significa cada mensaje?

| Mensaje       | Qué quiere decir                                 |
| ------------- | ------------------------------------------------ |
| **LIVE**      | Hay una lectura reciente                         |
| **STALE**     | La última lectura es antigua                     |
| **NO DATA**   | No hay un dato disponible para mostrar           |
| **UNMAPPED**  | Todavía no se ha asociado una señal a ese equipo |
| **AVAILABLE** | Una posición está libre                          |
| **OCCUPIED**  | Una posición ya está ocupada                     |
| **CONNECTED** | Hay una conexión registrada                      |

## ¿Qué puedo hacer?

Si una lectura aparece como antigua o no disponible, anota el **equipo**, la **hora** y el **mensaje** que ves. Comparte esa información con la persona responsable del sistema.

## Algo importante

Que un equipo muestre **NO DATA** no permite concluir que está apagado. Solo indica que Site Mapper no tiene una lectura disponible en ese momento.

**Al terminar:** podrás entender el estado que aparece en pantalla y comunicar el problema con claridad.
